# IoT-Based Smart Energy Meter ⚡

An advanced energy monitoring and management system built with **NodeMCU ESP8266**. This project allows users to monitor real-time electrical parameters (Voltage, Current, Power) and control appliances remotely via an IoT dashboard.

## 🚀 Key Features
* **Real-time Monitoring**: Tracks Voltage (V), Current (A), and Power (W) with high accuracy.
* **Remote Appliance Control**: Switch home appliances like Fans or Bulbs ON/OFF from anywhere using a mobile app.
* **LCD Feedback**: 16x2 LCD display for local monitoring of energy data.
* **Cloud Integration**: Real-time data logging and graphical analysis on the IoT cloud.

## 🛠️ Hardware Specifications
* **Controller**: NodeMCU ESP8266.
* **Sensors**: ZMPT101B Voltage Sensor & ACS712 Current Sensor.
* **Display**: 16x2 LCD with I2C Module.
* **Switching**: 5V Dual Channel Relay Module.
* **Safety**: Glass Fuse and AC Cooling Fan.
